### Method and source-class rule

The prerequisite reader projection was generated without hand-ledger input. The corpus inventory then split task rows into named fields, and prose into punctuation-delimited candidate units with enclosing section and original physical line range. Malformed wave-2 rows retain numbered fragments and are not assigned guessed columns. Ruling headings stay section locators, not invented authenticated events. Generic table rows and code/schema blocks are retained as candidates and can be compound. This deliberately exposes unfinished atomization rather than claiming a sentence splitter measures propositions. Evidence: `inventory.py`, `proposition-candidates.jsonl`, `reviewed-index.jsonl`.

The checked short-result matrix distinguishes identity, display kind, owner, acceptance route, deliverable, lifecycle completion, acceptance, commit token and remaining declaration: nine units per row, 36 short-result units; with the 15 hero units the reported coded total is 51. Each trace goes to a snapshot/contract, completion event, or ruling sequence. The study’s 27 narrow literal field checks were also re-executed. Generic normalized text matches into other artifacts were downgraded to U discovery pointers during review: a matching sentence in another wave is not evidence of authority or applicability. Evidence: `review-index.py`, `review-stats.json`; the decisive-observation matrices supply separately inspected artifact joins.

Classification priority proposed for acceptance (I / UNVERIFIED):

1. **Retained-structured:** this exact claim is stated in the selected task/assignment/ruling/completion, with source identity. A prose summary is still retained-structured; lack of typed subfields does not erase it.
2. **Retention gap:** the authoritative source generation needed for the claim is outside the retained window. Search the committed-artifact arm separately; do not diagnose an absent late task as a schema defect.
3. **Source-adapter/link gap:** an existing immutable artifact or source text already states the claim, but the projection needs a locator, role or reviewed semantic join. An unrelated token hit is not enough.
4. **Existing-authority schema gap:** the authority is present, but a required machine-readable relationship/value is genuinely missing; repair that authority, not a second ledger store. Recorded budget prose versus typed old/new/counting semantics is the worked example.
5. **New authored declaration:** an explicit scope outcome, remaining obligation, governance decision or qualification really must be authored. Under the binding adjudication the existing artifact can carry that declaration; a separate entry file is needed only if it exists nowhere else. Do not force a second authoring ceremony or infer absence from failed phrase search.

A proposition can have a primary cause plus an unresolved alternative: e.g. a late PASS may be a task-retention gap and a recoverable artifact assertion. The five classes are causal judgments, not five mutually exclusive storage formats. The matrix must say which authority and which claim it means. This priority is grounded in `docs/design/ledger-append-log-research.md:61–97,171–184,415–424` and `docs/design/mesh-next-adjudication.md:34–68`; it is not acceptance-owner approval.
