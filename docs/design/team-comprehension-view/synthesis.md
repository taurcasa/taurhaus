# Team-comprehension view — orchestrator synthesis

Two independent xhigh brainstorms (Fable-family: `concept-fable-the-site.md`;
GPT-6 Astra: `concept-astra-product-cutaway.md`) against one brief. This
records where they converged (treat as settled), where they genuinely
disagreed (the design decisions), and the recommended merged v1. Status:
awaiting operator direction; the build follows the design-led loop after the
wave-1 retro sharpens requirements.

## Convergence — settled by independent agreement

1. **Anchor on the product, and the scope stays still while work moves
   through it.** Both reject feeds, re-sorting, and layout driven by
   activity. The view is a place; change expresses as light/marks, never
   motion.
2. **The scope map is declared, never inferred.** Both explicitly refuse
   LLM-grouped or files-touched-derived structure in v1 — a plausible guess
   must never become the skeleton of the interface.
3. **Unknowns are rendered space.** Unmapped/unplaced work is a visible
   shelf with an always-adjacent fraction; empty regions say "no linked
   evidence", which is not "no work happened".
4. **No synthetic progress.** No percentages, no manufactured region
   completion; only clickable evidence-backed counts, every visual state
   traceable to a record on hover/inspect.
5. **A lens, not a second board.** Depth beyond two levels deep-links into
   the existing Task Board / Files / Git / terminal surfaces.
6. **A rejection is not an operator-decision.** A real decision-request
   needs an explicit typed contract (recipient, question, choices) — later
   convention, never inferred in v1.
7. **Activity honesty is inherited** from `activitySignal` verbatim
   (confidence, retained, offline), and assignment vs observed activity are
   separate claims shown separately.

## Divergences — the decisions, with calls

## Recommended v1 (one contained feature PR)

Fixed scope regions projected from addressed BRIEF.md headings; task
association via one `Scope:` line; chips-on-blocks with inherited activity;
contested/stalled flags from rulings + telemetry; the walk strip over
record-timestamped events with a local read-mark; unplaced shelf with
fraction; source-freshness bar; block inspection drawer that deep-links into
existing surfaces; draft-beside-pane handles. Deliberately omitted: any
inference, architecture edges, decision-request contract, milestone overlay,
time scrubbing, direct ledger mutation.

The degenerate state (no addressed headings yet) renders the ledger-only
evidence strip plus the adoption prompt — useful from day one, per both
concepts.

## Why both documents matter

Fable designed the operator moment (the thirty-second reabsorption test, the
walk, constancy-plus-light); Astra designed the evidence contract (the
may-say / cannot-establish tables, freshness vs event age, verdict
provenance). The merged view is the ritual wearing the contract.
