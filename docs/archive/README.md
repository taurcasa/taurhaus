# Documentation archive

Historical documentation lives here when it still has reference value but should not stay in the active docs surface.

Use the active docs tree for current contributor and user guidance:
- `docs/architecture/` for current system design
- `docs/features/` for user-facing behavior
- `docs/operations/` for build/test/release procedures
- `docs/security/` for current security posture and active risk tracking

Move material into `docs/archive/` instead of deleting it when it is:
- superseded by current documentation
- a point-in-time audit, retro, migration note, or investigation
- planning or design exploration that is no longer the active implementation target

Current archive groups:

| Path | Contents |
|---|---|
| `docs/archive/architecture/` | Historical architecture explorations, drift reports, and superseded design work |
| `docs/archive/audits/` | Point-in-time audit reports and assessments |
| `docs/archive/design/` | UI and workflow explorations that are not active specs |
| `docs/archive/planning/` | README planning, shot lists, and other short-lived documentation plans |
| `docs/archive/security/` | Historical security audits |
